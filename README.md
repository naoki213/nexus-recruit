# NEXUS Inc. Careers

「入社1日目から、5年目まで。」をテーマにした、架空IT企業の体験型採用サイトです。

## Portfolio demo

- NEXUS Inc. は実在しない架空企業です。
- 募集要項、給与、福利厚生、会社データはすべてポートフォリオ用のデモ情報です。
- ENTRYフォームはデモであり、入力内容の送信・保存は行いません。

## Visual assets

人物写真3点は OpenAI ImageGen で本サイト用に生成しました。外部ストック素材は使用していません。

## Development

```bash
npm install
npm run dev
```
